# gradient-color-generator
Generate random HEX color palettes with animated gradients and one-click copying.


🎨 Gradient Color Generator

🔴 Live Preview: https://inzyhere.github.io/gradient-color-generator/
A simple and interactive Gradient Color Generator built using HTML, CSS, and JavaScript.

Generate random HEX color palettes, explore animated gradients, and copy your favorite colors with a single click.

✨ Features

- 🎨 Generate 4 random HEX colors.
- 🌈 Animated gradient background with multiple colors.
- ▶️ Play and pause color generation.
- 🔄 Resume color generation whenever you want.
- 🖌️ Live color preview.
- 📋 Copy individual HEX color values with one click.
- ✅ Copy confirmation on the clicked button.
- 💎 Modern glassmorphism UI.
- 📱 Responsive design for mobile devices.
- ♿ Keyboard focus styling and reduced-motion support.

🛠️ Built With

- HTML5 — Application structure
- CSS3 — Animated gradients, glassmorphism, responsive design
- JavaScript — Random color generation, interval controls, DOM manipulation, clipboard functionality

🚀 Getting Started

Run Locally

1. Clone this repository:
   
   git clone (https://github.com/inzyhere/gradient-color-generator)

2. Open the project folder:
   
   cd gradient-color-generator

3. Open "index.html" in your browser.

You can also use a local development server such as VS Code Live Server.

🎮 How to Use

1. Click PLAY to start generating random HEX colors.
2. Watch the background gradient and color palette update.
3. Click PAUSE when you find a palette you like.
4. Click the COPY button beside any HEX value to copy it.
5. Click RESUME to continue generating colors.
